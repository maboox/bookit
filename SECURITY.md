# Security policy

Security fixes target the latest 2.x release. Please use GitHub's private
[vulnerability reporting](https://github.com/maboox/bookit/security/advisories/new)
for security reports. Do not publish credentials, personal notes, backup files or
private article content in an issue. If private reporting is unavailable, open a
minimal issue asking for a private reporting channel without exploit details.

The repository includes a security review and its limitations in
[docs/SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md). Automated scans do not establish
that software is free from vulnerabilities.

برای گزارش امنیتی از گزارش خصوصی گیت‌هاب استفاده کنید. رمز، کلید، فایل پشتیبان
یا یادداشت شخصی را در ایشو عمومی قرار ندهید.
